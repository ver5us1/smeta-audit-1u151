# Методология

## 1. Рамка анализа

ВКР рассматривает проверку проектно-сметной документации капитального ремонта установки 1У-151 Астраханского ГПЗ. В проекте разделены два слоя:

1. **Расчётный слой Excel → Python.** Три листа с расчётами по объекту 1У-151 перенесены в функции с именованными входами и промежуточными результатами.
2. **Аналитический слой замечаний.** Таблицы ВКР преобразованы в CSV и используются для агрегации, визуализации и сценарного сравнения.

## 2. Формулы

### Командирование

```text
КЦ = ceil(Т / Н)
ЗЖД = (Чв1×Сжд1 + Чв2×Сжд2 + Чв3×Сжд3) × КЦ × 2 / 1000
Зсут = Зп × Σ(Чв_i×(tм_i−1)) × КЦ × 2 / 1000
t = 2×S1/V
П = ceil(Чв/В)
ЭАВТ = round(t, 2) × П × КЦ
ЗАВТ = ЭАВТ × С1 / 1000
Зпр = Ск × Чв × tд × Т / 1000
Зобщ = ЗЖД + Зсут + ЗАВТ + Зпр
```

Округление длительности автобусного цикла и стоимости перевозки повторяет исходный Excel.

### Перевозка работников

```text
П1 = ceil(Чв / В)
t1 = 2×S2 / V2
Э = round(t1, 2) × П1 × Т × Кр.дн
Зп = Э × С2 / 1000
```

### Специальные мероприятия

```text
Зсет = С3 × Nсезон × Чобщ / 1000
Зр = (С4 + С5) × Nсезон × Чобщ / 1000
Згнус = Зсет + Зр
```

## 3. Стоимостное влияние замечаний

Для детального расчёта используется знак направления, а не попытка представить все замечания как экономию:

```text
чистое влияние = увеличение стоимости − снижение стоимости
```

Положительное значение означает риск недоучёта затрат. Отдельно показана оценочная часть по 97 замечаниям, потому что её исходные данные неполны.

## 4. Контроль округления

В таблицах ВКР итоговые значения округлены отдельно от строк. Поэтому строковая сумма детальной выборки равна 26 521,24 тыс. руб., а опубликованный итог — 26 521,25 тыс. руб. Разница 0,01 тыс. руб. сохранена как результат аудита, а не исправлена молча.
